# Phase 5 – Project Development

The completed application source remains at the repository root so that the existing Python imports and deployment configuration are not unnecessarily changed.

## Existing Source Code

- `backend/` – FastAPI backend, AI integration, schemas, routes and formatting services
- `frontend/app.py` – Streamlit frontend
- `assets/` – project assets
- `requirements.txt` – Python dependencies
- `Dockerfile` – container configuration
- `docker-compose.yml` – local multi-service configuration
- `Procfile` – deployment process definition
- `.env.example` – public environment-variable template

## Main Development Components

- FastAPI API
- Streamlit user interface
- Google Gemini integration
- Document formatting
- TXT/DOCX/PDF output
- API tests

**Note:** The source folders are intentionally not duplicated into this phase folder. This keeps one authoritative copy of the working application.

# LegalEase – Demo Script

## 1. Project Name
My project is LegalEase – an AI-Powered Legal Document Generator.

## 2. Purpose
The purpose of LegalEase is to make legal document creation simple and accessible. It generates documents based on user-provided details using AI.

## 3. Benefits
LegalEase is useful for individuals, freelancers, entrepreneurs, and professionals. It saves time and allows users to generate, edit, and download legal documents in TXT, DOCX, and PDF formats.

## 4. Demonstration
1. Open the LegalEase application.
2. Show the project name and interface.
3. Select a document type.
4. Enter parties involved.
5. Enter terms/conditions.
6. Select the effective date.
7. Click **Generate Document**.
8. Explain the generated document.
9. Demonstrate editing/preview.
10. Download TXT, DOCX and PDF outputs.
11. Show the final output.

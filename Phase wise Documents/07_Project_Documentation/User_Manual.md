# LegalEase – User Manual

## Purpose
LegalEase is an AI-powered legal document generator that helps users create editable document drafts from supplied information.

## How to Use

1. Start the LegalEase application.
2. Select a document type.
3. Enter the parties involved.
4. Enter the terms or conditions.
5. Select the effective date.
6. Click **Generate Document**.
7. Review the generated content.
8. Edit the document if required.
9. Download the result in the available TXT, DOCX or PDF formats.

## Security
Keep API credentials in environment variables. Never publish a real API key in GitHub.

## Legal Notice
Generated documents should be reviewed carefully and should not be treated as a replacement for qualified legal advice.
